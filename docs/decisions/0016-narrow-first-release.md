# 0016：收窄第一版——只清理 AI 狂飙留下的悬空残留

日期：2026-10-10。状态：用户批准的方向与第一版范围。
取代 [0015](0015-reference-evidence-policy.md) 草案；0015 仅作历史保留。

## 为什么转向

此前的目标逐渐变成"绝不说错话"：大结论加满免责，治理文档比代码长，
检测器靠正则抓"像路径的文字"再靠过滤补救。结果是 MarkItDown 上 118 条断链几乎全是
`result.markdown` 这类代码误报，默认审查全部过滤掉；唯一确认的真问题（`SUPPORT.md`
未替换的模板文字）没有被展示。样样都有，没有一样经得起追问。

不说错话靠的是**缩小主张**，不是给大主张加免责。

## 线索分三类

按"判断一条线索需要多少知识"分，而不是按"工程还是 AI"分：

| 类别 | 需要的知识 | 谁判断 |
| --- | --- | --- |
| A 文本自证 | 只看这段文字 | 工程，直接断言 |
| B 局部上下文 | 再看一两个相关文件 | 用户的 AI，读一小圈 |
| C 作者意图 | 只有作者知道 | 问作者，记住答案 |

RepoGC 不尝试理解整个项目。

## 残留分两种

- **悬空残留**：有东西指向已不存在的东西，或模板文字从未替换。属于 A 类，可以直接断言。
- **遗弃残留**：版本并存、`old`/`backup` 副本、近似重复、陈旧状态。只能提问——
  `plan_v1` 与 `plan_v2` 可能本来就是有意并存。

## 第一版范围

只做两件事，做到误报接近零：

1. **断链**：只检查真正的 Markdown 链接、图片、引用定义和 HTML `href`/`src`；
   代码块、行内代码、HTML 注释里的内容不算。按源文件目录解析相对路径，
   找不到就报。外部 URL、锚点、绝对路径、模板变量、仓库外路径不检查。
2. **模板占位符**：如 `INSERT ... HERE`、`REPO MAINTAINER:`、
   `has not yet edited this file`。模板目录本身（如 `.github/ISSUE_TEMPLATE/`）不检查。

原有的正则路径识别保留为孤儿/可达性分析的上下文证据，不再产生断链结论。
遗弃残留、AI 调查交接、决定包和 Gate 0–6 实现全部暂缓。
