# README artwork

`repogc-hero.png` is an original AI-generated illustration made for this project
using the built-in image-generation tool. It is decorative branding, not a
screenshot of product output or evidence of implemented capabilities.

Generation brief: a spacious 3:1 GitHub README banner with a dark graphite
background, ivory typography and restrained mint-lit connections between
translucent documents. Exact text: “RepoGc” and “Investigate before changing it.”
Avoid robots, trash bins, deletion imagery, fake code and performance claims.

The visual represents investigating relationships before changing a repository.
The source PNG is used without compositing or content edits.
